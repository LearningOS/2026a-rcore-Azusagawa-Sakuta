1. 由于 linkat 和 unlinkat 都需要用到 ROOT_INODE 中的私有方法，所以这里选择把 link 和 unlink 实现为 Inode 结构体的方法。
    - link 做的就是把目录重新写一份，加一个文件并且把这个文件对应到被链接的文件的 inode 上
    - unlink 做的是把目录中的这个文件删掉
    - 两者都更新文件的 nlink 计数（在 Inode 结构体中加入这个 field），方便 fstat 管理统计
    - fstat 实现过程中，在 File Trait 下面加了一个 stat 方法和他的默认实现，并让 OSInode 实现这个方法，这样就可以保证调用 fstat 的 dyn File 方法有 stat 方法，并且我们的 fs 中均为 OSInode 方法，可以直接取得他的状态。后续的工作和 sys_write 相似，写入内存就可以了
